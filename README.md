## Overview

Soundtoys FilterFreak models vintage analog filter circuits with rich resonance, tempo-synchronized LFO modulation, and a tactile interface for aggressive and subtle filter effects.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys FilterFreak** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Analog Filter** | Two-pole and four-pole filter models with warm analog resonance |
| **Rhythm Sync** | Pattern-based filter modulation synced to host BPM |
| **Series Mode** | FilterFreak 2 chains two filter instances in series for complex filtering |
| **Feedback Path** | Additional feedback path creates comb filter and resonator effects |
